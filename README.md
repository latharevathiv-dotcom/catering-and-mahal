# 🍽️ Kanna Catering & Mahal Website

A responsive **Catering & Mahal Website** built using **HTML, CSS, and JavaScript**. This project showcases catering services, marriage hall details, and contact information with a clean and user-friendly design.

---

## ✨ Features

- 🏠 Home Page
- 🍴 Catering Services
- 🏛️ Marriage Hall (Mahal) Information
- ℹ️ About Us
- 📞 Contact Page
- 📱 Responsive Design
- 🧭 Easy Navigation

---

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
